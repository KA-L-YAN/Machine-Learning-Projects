Saved Posts Cleaner

Unsaves every post in your Instagram Saved list from your phone's browser. Saved audio and music aren't touched. It runs inside instagram.com where you're already logged in, so you never type your password here.

Step 1: Copy the button code

Step 2: Save it as a bookmark

  1. On this page, tap Share → Add Bookmark. Name it Unsave and save.
  2. Tap the Bookmarks icon → Edit → tap Unsave.
  3. Clear the address field completely, paste the copied code, tap Done. It should start with javascript:(async.
  4. Open instagram.com in Safari and log in. If it jumps to the app, long-press the link and choose Open, or type it in the address bar.
  5. Tap Bookmarks → Unsave. A panel appears at the bottom. Tap Unsave all.
  1. On this page, tap ⋮ → the ☆ star to bookmark it.
  2. Tap ⋮ → Bookmarks, find the new bookmark, tap its ⋮ → Edit.
  3. Rename it Unsave. Clear the URL field completely, paste the copied code, go back to save. It should start with javascript:(async.
  4. Open www.instagram.com in Chrome and log in.
  5. Tap the address bar, type Unsave, and tap the bookmark suggestion (it starts with javascript:). Tapping the bookmark from the Bookmarks list doesn't run it on Android. Then tap Unsave all.
Before you start
  • It waits about 2–3 seconds per post, so 300 posts take about 15 minutes. Keep the tab open and the screen on.
  • If Instagram starts limiting requests, it stops on its own. Wait an hour and run it again; it picks up whatever is left.
  • This uses Instagram's unofficial web API, so it could stop working if Instagram changes things.
